# Setups by Use Case

Linux is the same operating system, but people use it in different ways. These guides help you choose the setup that matches your needs.

Each category page is written for beginners. It explains what the setup is for, suggests Linux distributions, and links to the project guides you need. These pages are documentation only: they do not include installation scripts.

## Choose a setup

| Setup | Best for | What you will set up |
|---|---|---|
| [Gaming](./gaming/README.md) | Playing games on Linux | Graphics drivers, Steam, game launchers, controllers |
| [Development](./development/README.md) | Writing code and building software | Code editor, Git, programming languages, containers |
| [Work](./work/README.md) | Office tasks and daily work | Office apps, email, video calls, cloud storage |
| [School](./school/README.md) | Studying and online classes | Note-taking, documents, PDFs, research tools |
| [Personal](./personal/README.md) | Everyday home use | Browser, media, photos, privacy, backups |

## How to use these guides

1. Pick the category that is closest to how you use your computer. You can follow more than one.
2. Choose a Linux distribution from the [Linux installation list](../README.md#linux-installation). If you are new to Linux, start with Ubuntu or Linux Mint.
3. Follow the category steps. Each step links to a detailed guide.
4. Keep your system updated and back up important files.

> New to Linux? Read the [project README](../../README.md) and the [Getting Started](../../README.md#getting-started) section first.
