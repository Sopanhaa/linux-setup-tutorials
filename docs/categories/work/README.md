# Work Setup on Linux

This guide helps you use Linux for everyday work: documents, email, video calls, and file storage. It is written for beginners and focuses on common office tasks.

> **Documentation only:** This page explains the steps and links to official resources. It does not include installation scripts.

## Is this setup right for you?

Choose this setup if you want to:

- Write documents, spreadsheets, and presentations.
- Read and send email and manage your calendar.
- Join video meetings.
- Store and share files in the cloud.
- Use a printer, scanner, or work headset.

## Before you start

- Check with your employer or IT team. Some required apps may not support Linux.
- Back up important files. See [Linux system maintenance](../../guides/system-maintenance.md).
- Install Linux. See the [distribution list](../../README.md#linux-installation).
- Connect to the internet.
- Make a list of the apps you must use for work.
- Have your work account details ready.

## Setup steps

1. **Install Linux.** Choose a distribution from the [distribution list](../../README.md#linux-installation) and follow its installation guide.
2. **Update your system.** Install updates from your software center or package manager. See [Package managers](../../guides/package-managers.md).
3. **Install an office suite.** [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/) is free and opens common document formats. [OnlyOffice](https://www.onlyoffice.com/download-desktop.aspx) is another option with a familiar layout.
4. **Set up email and calendar.** Use [Thunderbird](https://www.thunderbird.net/) or open your work email in a browser.
5. **Install a browser.** [Firefox](https://www.mozilla.org/firefox/) is a good default. Some work apps work best in a browser.
6. **Set up video calls.** Install [Zoom](https://zoom.us/download?os=linux) or [Microsoft Teams](https://www.microsoft.com/en-us/microsoft-teams/download-app) if your workplace uses them. Test your camera and microphone before an important meeting.
7. **Set up cloud storage.** Use your provider's website or official app. [Nextcloud](https://nextcloud.com/install/) and [rclone](https://rclone.org/downloads/) are useful options for some setups.
8. **Set up your printer or scanner.** Open your distribution's printer settings and follow the on-screen steps. Check your distribution guide for extra help.
9. **Protect your work.** Turn on updates, use a firewall, use a password manager, and keep backups. See [Linux system maintenance](../../guides/system-maintenance.md).
10. **Test your required apps.** Open each work app and sign in before you rely on it for an important task.

## Important compatibility note

Some work software does not support Linux. This includes some versions of Microsoft 365 desktop apps, some company VPN clients, and some security tools. Use the web version when possible, and ask your IT team for a supported option.

Do not bypass company security rules or install unofficial workarounds. If an app is required for your job, ask your employer for help.

## Beginner tips

- Keep work files separate from personal files.
- Use a password manager instead of reusing passwords.
- Back up important documents regularly.
- Test your camera, microphone, and screen sharing before meetings.
- Download apps from official websites or your distribution's software center.
- Keep your system updated, especially for security fixes.
