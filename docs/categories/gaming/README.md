# Gaming Setup on Linux

This guide is for beginners who want to use Linux for gaming. It explains what to prepare, which tools are useful, and where to find help.

> **Documentation only:** This page explains the steps and links to official resources. It does not include installation scripts.

## Is this setup right for you?

Choose this setup if you want to:

- Play games from Steam, GOG, Epic Games Store, or other game stores.
- Use a controller, headset, or gaming mouse.
- Get better performance from your graphics card.
- Learn how Linux runs Windows games with compatibility tools.

Linux gaming works well for many games, but not every game supports Linux. Check the game's store page and [ProtonDB](https://www.protondb.com/) before you buy.

## Before you start

- Back up important files. See [Linux system maintenance](../../guides/system-maintenance.md).
- Install Linux or set up a dual-boot system. See [Dual-booting Linux and Windows](../../guides/dual-boot.md).
- Connect to the internet so you can download updates and games.
- Know your graphics card: AMD, Intel, or NVIDIA.
- Have your game store account details ready.

> Always back up important files before installing Linux or changing disk partitions.

## Recommended distributions

Most Linux distributions can run games. These are good starting points for beginners:

| Distribution | Why it may suit you |
|---|---|
| [Ubuntu](../../ubuntu/README.md) | Large community, easy driver support, and many guides. |
| [Linux Mint](../../linux-mint/README.md) | Simple desktop and a familiar layout for Windows users. |
| [Fedora](../../fedora/README.md) | New software and good support for modern hardware. |
| [openSUSE](../../opensuse/README.md) | Strong desktop tools and good hardware support. |

## Setup steps

1. **Install Linux.** Choose a distribution from the [distribution list](../../README.md#linux-installation) and follow its installation guide.
2. **Update your system.** Open your software center or package manager and install updates. See [Package managers](../../guides/package-managers.md).
3. **Install graphics drivers.** Better drivers can improve game performance. See [Graphics drivers](../../guides/graphics-drivers.md).
4. **Choose a desktop environment.** Some desktops are lighter or work better with gaming features. See [Linux desktop environments](../../guides/desktop-environments.md).
5. **Install your game store.** Download Steam from the official website or install it from your distribution's software center.
6. **Turn on Steam Play (Proton).** In Steam, open **Settings → Compatibility** and enable Steam Play for supported titles. Proton helps run many Windows games on Linux.
7. **Install extra tools if needed.** Use the table below to find launchers and performance tools.
8. **Test one game.** Start with a game that has native Linux support or a high ProtonDB rating.
9. **Keep your system healthy.** Install updates, watch your disk space, and keep backups. See [Linux system maintenance](../../guides/system-maintenance.md).

## Helpful tools

| Tool | What it does | Official page |
|---|---|---|
| Steam | Store and game launcher with Proton support. | [store.steampowered.com](https://store.steampowered.com/) |
| ProtonDB | Community reports about how well games run on Linux. | [protondb.com](https://www.protondb.com/) |
| Lutris | Helps manage games from many stores and emulators. | [lutris.net](https://lutris.net/) |
| Heroic Games Launcher | Launcher for Epic Games, GOG, and Amazon Games. | [heroicgameslauncher.com](https://heroicgameslauncher.com/) |
| Bottles | Runs Windows applications and game launchers in containers. | [usebottles.com](https://usebottles.com/) |
| MangoHud | Shows performance information while you play. | [GitHub](https://github.com/flightlessmango/MangoHud) |

Install tools from official sources or your distribution's software center. Avoid random scripts from the internet.

## Beginner tips

- Check [ProtonDB](https://www.protondb.com/) before buying a game.
- Start with games that have native Linux support.
- Keep your graphics drivers and system updated.
- On laptops, check whether games use the correct graphics card.
- Do not disable Secure Boot, your firewall, or other security features as a first step. Ask for help in a community forum if a game will not start.
