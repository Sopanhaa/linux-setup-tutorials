# Personal Setup on Linux

This guide helps you set up Linux for everyday home use: browsing the web, watching videos, listening to music, managing photos, and keeping personal files safe.

> **Documentation only:** This page explains the steps and links to official resources. It does not include installation scripts.

## Is this setup right for you?

Choose this setup if you want to:

- Browse the web and use email.
- Watch videos and listen to music.
- Organize and edit photos.
- Play games in your free time.
- Keep personal files private and backed up.
- Make the desktop look and feel the way you like.

## Before you start

- Back up important files before you change your system. See [Linux system maintenance](../../guides/system-maintenance.md).
- Install Linux. See the [distribution list](../../README.md#distributions).
- Connect to the internet.
- Think about the apps you use every day.
- Plan where you will keep backups, such as an external drive or cloud storage.

## Setup steps

1. **Install Linux.** Choose a distribution from the [distribution list](../../README.md#distributions) and follow its installation guide.
2. **Update your system.** Install updates from your software center or package manager. See [Package managers](../../guides/package-managers.md).
3. **Install a browser.** [Firefox](https://www.mozilla.org/firefox/) is a good default. Sign in and import bookmarks if you need them.
4. **Set up media playback.** [VLC](https://www.videolan.org/vlc/) plays most video and audio formats. [Spotify](https://www.spotify.com/download/linux/) is available for music streaming.
5. **Organize your photos.** Use your distribution's photo app or install [GIMP](https://www.gimp.org/downloads/) for image editing and [Krita](https://krita.org/en/download/) for drawing.
6. **Install the apps you use.** Add the apps you need from your distribution's software center. Avoid random scripts from the internet.
7. **Set up backups.** Use an external drive, cloud storage, or a backup app. Test that you can restore a file before you need it.
8. **Protect your privacy and security.** Keep updates on, use a firewall, and use a password manager such as [Bitwarden](https://bitwarden.com/download/).
9. **Customize your desktop.** Change the wallpaper, theme, and panel layout. See [Linux desktop environments](../../guides/desktop-environments.md).
10. **Learn a few terminal basics.** Simple commands can help you fix problems and understand your system. See [Basic Linux commands](../../guides/basic-commands.md).

## Beginner tips

- Keep personal files in your home folder so they are easy to find and back up.
- Back up important files regularly.
- Use official software sources.
- Keep automatic updates turned on.
- Use a password manager and a unique password for each account.
- Do not disable your firewall or other security features as a first step.
