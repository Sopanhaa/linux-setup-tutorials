## Linux Installation

Each distribution follows the same six-page learning path: introduction,
download, installation, initial setup, desktop setup, and troubleshooting.

| Distribution | Description | Learning path | Official website |
|---|---|---|---|
| Ubuntu | Beginner-friendly Linux desktop | [Ubuntu](./ubuntu/README.md) | [Website](https://ubuntu.com/) |
| Fedora | Modern Linux for desktop users and developers | [Fedora](./fedora/README.md) | [Website](https://fedoraproject.org/) |
| Arch Linux | Flexible and customizable Linux | [Arch Linux](./arch-linux/README.md) | [Website](https://archlinux.org/) |
| Debian | Stable and community-driven Linux | [Debian](./debian/README.md) | [Website](https://www.debian.org/) |
| Linux Mint | Easy-to-use desktop Linux | [Linux Mint](./linux-mint/README.md) | [Website](https://linuxmint.com/) |
| openSUSE | Linux for desktops and developers | [openSUSE](./opensuse/README.md) | [Website](https://www.opensuse.org/) |
